# michaltobiasdobes.cz

Osobní web Michala Tobiáše Dobeše — statické HTML/CSS, žádný framework, žádný build krok.

**Živá stránka:** https://dobes-michal-tobias.github.io/michal-tobias-dobes.cz/
*(vlastní doména `michaltobiasdobes.cz` je v plánu, zatím nenasazená)*

## Struktura

- `index.html`, `projekty.html` — hlavní stránky (CZ), `en/` — jejich anglické protějšky
- `projekty/*.html` — jednotlivé podstránky projektů
- `styles.css` — sdílený design systém pro celý web
- `assets/` — obrázky, grafy a další statické soubory

Detaily designového systému a konvencí viz [`CLAUDE.md`](CLAUDE.md).
